# CloneSpotifyTailwind

![Badge de Status do Projeto](https://img.shields.io/badge/Status-Conclu%C3%ADdo-brightgreen)

## 📝 Descrição

Este projeto é um clone da interface do usuário do Spotify, desenvolvido com foco em replicar o design e a responsividade utilizando HTML e Tailwind CSS. O objetivo principal foi praticar e demonstrar habilidades em estilização moderna e construção de layouts flexíveis e adaptáveis a diferentes tamanhos de tela.

## ✨ Funcionalidades

*   **Layout Responsivo:** Adapta-se a dispositivos móveis, tablets e desktops.
*   **Navegação:** Estrutura de navegação lateral e superior, similar à do Spotify.
*   **Componentes Visuais:** Recreação de elementos como barra de reprodução, listas de músicas/álbuns e cards de artistas.
*   **Estilização com Tailwind CSS:** Utilização de classes utilitárias para um desenvolvimento rápido e consistente do design.

## ⚙️ Instalação e Configuração

Para visualizar e rodar este projeto localmente, siga os passos abaixo:

```bash
# Clone o repositório
git clone https://github.com/LucasDuarte42/CloneSpotifyTailwind.git

# Navegue até o diretório do projeto
cd CloneSpotifyTailwind

# Abra o arquivo index.html no seu navegador preferido
# Exemplo (no Linux/macOS):
open src/index.html
# Exemplo (no Windows):
start src/index.html
```

## 💡 Como Usar

Após abrir o arquivo `index.html` no navegador, você poderá navegar pela interface do clone do Spotify. Explore os diferentes elementos e observe a responsividade ao redimensionar a janela do navegador.
